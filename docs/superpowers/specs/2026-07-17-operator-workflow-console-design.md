# 운영 워크플로 콘솔 구현 설계

## 승인된 화면 구성

목록과 고정 상세 패널을 한 화면에 배치한다. 운영자는 목록에서 Run을 고르고, 같은 화면의 상세 패널에서 6단계 진행·Attempt·결정 액션을 확인한다.

## 1차 구현 범위

- Vue 3 컴포넌트와 `/workflow-runs` 라우트를 추가한다.
- 목록·상세·결정 상태는 명세와 동일한 목업 데이터로 동작한다.
- 검색·상태 필터·선택 Run 변경·결정 버튼은 로컬 상태를 갱신한다.
- API 요청서의 계약이 준비되면 목업 데이터 모듈을 `EngineWorkflowApi` 호출로 교체한다.

## 제외 범위

- Ticket 제목·프로젝트·우선순위 표시
- 실시간 갱신, 권한 관리, 산출물 원문 렌더링
- 백엔드 API 구현

## 컴포넌트와 데이터 흐름

`WorkflowConsole.vue`가 목업 Run 목록과 선택 상태를 소유한다. 목록은 필터된 Run을 렌더링하고, 상세 패널은 선택 Run의 단계와 Attempt 이력을 렌더링한다. 결정 버튼은 선택 Run의 상태와 타임라인을 갱신한다.

## 테스트

빌드 가능한 Vue 화면을 검증하고, 목업 상태 변환은 화면 테스트가 가능한 환경이 도입될 때 별도로 검증한다. 현재 `frontend/package.json`에는 테스트 러너가 없다.
